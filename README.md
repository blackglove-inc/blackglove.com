# blackglove.com

Static export of the Black Glove website, served via GitHub Pages.

Ported from WordPress on Pantheon (2026-07-27) as part of the migration off
Pantheon hosting. Content was mirrored from the live site, with WordPress
runtime machinery (wp-json, feeds, query-string asset versions) stripped.

- Contact form: HubSpot embed (works statically)
- Analytics: Fathom (works statically)
- Full WordPress code/database/files archive is retained privately offline —
  not in this repository.

To update content, edit the HTML directly and push to `main`.
